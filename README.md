# 宿舍人生 · 我们的四年

> 四张床，三个陌生人，和一个很长很长的夏天。

一部关于大学四年的互动小说。你住进 7 号楼 404，遇见三个室友和一个会让你心动的人。四年里你做的每一个选择——陪谁守夜、借不借钱、去不去车站——会改变他们每个人的十年。

**手机优先**：竖屏设计，单手就能玩；可以「添加到主屏幕」当 App 用，离线也能玩。

## 它是什么

- **一个完整的故事，而不是两万条随机事件。** 30+ 个手写剧情场景、40 个校园碎片，每局约 1.5 万字、50 次选择。
- **每个人都有自己的四年。**
  - 江野——篮球特长生，大二那场比赛摔断了腿。你会不会每天早上六点陪他去复健？
  - 苏念——村里第一个大学生，大三那年父亲出事，想休学去电子厂。你能不能把苏念留下来？
  - 许多——家里让学金融，自己只想写歌。他在火车站给你发消息：「还剩四十分钟。」
  - 林溪——雨夜图书馆门口擦镜头的那个人。你可以撑伞送林溪回去，也可以戴上耳机冲进雨里，从此错过。
- **结局是一本毕业纪念册。** 你的去向（19 种）、每个室友的十年后（各 3–4 种）、林溪（6 种）、十年后 404 能聚齐几个人（4 种），加上一个属于你的称号。
- **会动的画。** 18 个地点 × 4 个时段 × 4 季 × 天气，全部程序化绘制：银杏落叶、初雪、春天的花瓣、夏夜的萤火虫、雨打在宿舍窗上。没有一张图片文件。
- **会响的夜晚。** WebAudio 生成的八音盒配乐，白天明亮、夜里低沉，下雨时有雨声。
- **玩法。** 每学期：开篇章节 → 剧情 → 安排时间（3 件事）→ 校园碎片 → 期末成绩单。四项状态（学业 / 体魄 / 心情 / 存款），心情或体魄见底时，关系最好的那个人会来找你。

## 怎么玩

**直接打开**：用浏览器打开 `index.html` 即可（离线模式，没有全服统计和留言墙）。

**带后端运行**（推荐，手机和电脑在同一个 Wi-Fi 下就能用手机玩）：

```bash
npm start            # 默认 http://localhost:8080
PORT=3000 npm start  # 换端口
```

用手机浏览器打开 `http://电脑的局域网IP:8080`，在浏览器菜单里选「添加到主屏幕」。

操作：点屏幕推进剧情；数字键 1–4 选择选项；`J` 手账；`M` 声音；`Esc` 菜单。

## 后端

`server/server.js`，零依赖 Node（≥18）：

| 接口 | 说明 |
| --- | --- |
| `GET /api/health` | 健康检查 |
| `POST /api/runs` | 匿名上报一局结局（白名单字段，4KB 上限，每 IP 每小时 20 次） |
| `GET /api/stats` | 全服统计：毕业人数、去向分布、关键选择比例 |
| `GET /api/wall` / `POST /api/wall` | 毕业留言墙（60 字以内，过滤广告/脏话，每 IP 10 分钟 3 条） |

- 数据存在 `server/data/db.json`（可用 `DATA_DIR` 改位置），写入走临时文件 + rename。
- 只对外提供游戏文件（白名单），后端源码、测试、配置一律 404。
- 部署在反向代理后面时设置 `TRUST_PROXY=1`，限频才会按真实 IP 计算。
- 静态部署（GitHub Pages 等）时前端自动降级为本地模式，游戏完整可玩。

## 目录

```
index.html            页面骨架
css/style.css         样式（手机优先）
js/engine.js          叙事引擎：脚本解释、状态、学期循环、存档（纯逻辑，可在 Node 里跑）
js/story/world.js     角色、社团、去向、学期结构、时间安排
js/story/y1~y4.js     四年的主线剧情
js/story/moments.js   校园碎片
js/story/endings.js   去向判定、每个人的十年后、重聚、称号
js/art.js             程序化插画 + 天气粒子
js/audio.js           生成式配乐
js/ui.js / main.js    界面与流程
js/api.js             后端接口（自动降级）
server/server.js      后端
sw.js / manifest      PWA：离线、添加到主屏幕
```

## 测试

```bash
npm test
```

- `tests/story.test.cjs`：随机跑 4000 局，检查不崩溃、没有残留模板文字、每种命运都能达到、存档能在任意节点恢复，并打印结局分布。
- `tests/server.test.cjs`：接口校验、路径穿越、限频、留言过滤。
- `tests/e2e.cjs`：在模拟 iPhone 13 上用真实点击打完一整局，要求零报错、后端收到上报。`SHOTS=目录 node tests/e2e.cjs` 会顺便截图。

## 写剧情

剧情是普通的 JS 数组，见 `js/engine.js` 顶部的说明：

```js
S.my_scene = {
  at: "rooftop", time: "night", title: "天台",
  steps: [
    "旁白。",
    ["xu", "许多的台词，{me} 会替换成玩家名字。"],
    { ask: "你要怎么做？", options: [
      { t: "选项一", fx: { mood: 5, rel: { xu: 6 } }, then: ["结果。"] },
      { t: "选项二", if: "band", fx: { set: { flag: true } } },
    ] },
    { mem: { id: "roof", title: "回忆标题", text: "收进相册的一句话。" } },
  ],
};
```
