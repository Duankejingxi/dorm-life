# 宿舍人生 · 大学四年模拟器

> 你 18 岁，考上大学，住进宿舍。先选家境和天赋，再过四年 8 个学期：每学期选 3 个行动（还能买东西），再遇到 2 件大事（可能是 3 环连锁剧情的一环）和 3 件随机小事，第 2/4/6 学期末还有寒暑假安排。大事件都有场景配图。毕业那天，看看你活成了什么样。

纯前端文字模拟游戏，打开就能玩，不用下载，不用注册，不用联网。

## 怎么玩

1. 输入名字，选**家境**（富裕/小康/拮据，影响开局金钱和属性）和**天赋**（学霸体质/运动健将/社交达人/幸运星/普通人，开局加成），点「开始大一」。
2. 每学期选 **3 个行动**：上课学习 / 打工赚钱 / 健身运动 / 打游戏 / 社交聚会 / 摆烂躺平，还能 **🛒 买东西**（新手机 ¥800、健身卡 ¥500、复习资料 ¥200、请客吃饭 ¥300，买一次算一个行动，花钱换属性）。
3. 再处理 **2 个大事件**：室友半夜开黑、食堂新开麻辣烫、捡到校园卡、表白墙挂你……244 个大事件，每个都有 2–3 个选择，后果各不相同，每个大事件都配一张**场景插画**（宿舍 / 教室 / 食堂 / 校园，根据事件内容自动匹配）。其中 15 条是 **3 环连锁剧情**（校园恋爱、创业梦、电竞之路、考研之路……），抽到第 1 环后，后续学期按顺序出第 2、3 环，有始有终，每学期只推进一环。24 个是**分学年专属事件**（大一第一次见室友、大三小美表白、大四十年之约……），每个学年都有自己的故事。
4. 穿插着还有 **3 件随机小事**：食堂鸡腿特别大、室友打呼噜、晚霞特别美……200 件小事，短平快，丰富日常。
5. 第 2/4/6 学期末还有**寒暑假安排**：回家陪父母、留校打工、和朋友旅游、留校复习，四选一，各有得失。
6. 8 个学期过完，毕业。结局由你的属性和**人际关系**决定。

每学期 8 个遭遇（3 行动 + 2 大事件 + 3 小事），一局 64 个遭遇，比 v1.2 多一倍；加上 3 次寒暑假安排，一局 67 个选择。

## 人际关系（v1.2）

你身边有 4 个人，关系 0–100，对他们好一点能解锁专属结局：

| 人物 | 身份 | 初始关系 | 怎么涨 |
| --- | --- | --- | --- |
| 阿强 | 室友 | 60 | 社交、健身、一起创业、宿舍夜聊 |
| 小美 | 同班同学 | 50 | 社交、借笔记、一起办活动、表白 |
| 学长 | 大三学长 | 40 | 社交、请吃饭、接受内推 |
| 导师 | 专业课老师 | 30 | 认真听课、加入项目、请他写推荐信 |

关系够铁能解锁专属结局：兄弟情深（阿强 ≥ 85）、终身伴侣（小美 ≥ 90）、得意门生（导师 ≥ 85）、贵人相助（学长 ≥ 85）。反过来，得罪了他们关系会掉。

毕业后，结局页有**「📋 复制分享」**（把你的结局 + 属性一键复制，发给朋友炫耀）和**「📖 人生回顾」**（8 个学期的完整记录，看看你都经历了什么）。

## 内容量（v1.3）

- 6 个学期行动 + **4 件商店商品**（新手机、健身卡、复习资料、请客吃饭）
- **244 个大事件**（220 个通用 + 24 个分学年专属，按学年出现）
- **200 件随机小事**（每学期 3 件）
- **15 条连锁剧情 × 3 环 = 45 个节点**（恋爱、创业、电竞、考研、兼职、社团、健身、学霸、主播、旅行、流浪猫、乐队、写小说、摄影、志愿者）
- **44 个结局**（含 4 个关系结局 + v1.4 新增 4 个：健身教练、考研落榜、考公落榜、旅行博主 + v1.5 新增 4 个：社团会长、校园歌手、辩论冠军、交换生）
- **25 个成就**
- **4 个 NPC 人际关系**（阿强、小美、学长、导师）
- **6 张场景配图**（宿舍 / 教室 / 食堂 / 图书馆 / 操场 / 校园，大事件按内容自动匹配，结局页配校园图）
- **开局系统**（3 种家境 × 5 种天赋，自由组合开局）
- **3 次寒暑假安排**（第 2/4/6 学期末，回家/打工/旅游/复习四选一）
- 1 个赌一把事件（彩票：12% 概率中 500）和 1 个刮刮乐（15% 概率中 100）

每学期 8 个遭遇（3 行动 + 2 大事件 + 3 小事），一局 64 个遭遇，是 v1.2（每学期 4 个遭遇）的 2 倍；加上 3 次寒暑假和 15 种开局组合，组合数是 v1.0 的几千倍以上。

## 文件结构

- `index.html` — 结构（开始 / 游戏 / 结局三个界面）
- `styles.css` — 样式（暖色卡片风）
- `data.js` — 内容数据：行动、事件、小事、连锁剧情、结局、成就和判定
- `scenes.js` — 场景配图（6 张插画，base64 内嵌）
- `game.js` — 游戏逻辑：流程、属性、存档、结局图鉴、成就

## 本地运行

直接用浏览器打开 `index.html` 就行；或者部署到 GitHub Pages。
