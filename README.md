# 宿舍人生 · 大学四年模拟器

> 你 18 岁，考上大学，住进宿舍。四年，8 个学期，每学期选一个行动，再遇到 1 件大事（可能是 3 环连锁剧情的一环）和 2 件随机小事。毕业那天，看看你活成了什么样。

纯前端文字模拟游戏，打开就能玩，不用下载，不用注册，不用联网。

## 怎么玩

1. 输入名字，点「开始大一」。
2. 每学期选 **1 个行动**：上课学习 / 打工赚钱 / 健身运动 / 打游戏 / 社交聚会 / 摆烂躺平。
3. 再处理 **1 个大事件**：室友半夜开黑、食堂新开麻辣烫、捡到校园卡、表白墙挂你……220 个大事件，每个都有 2–3 个选择，后果各不相同。其中 15 条是 **3 环连锁剧情**（校园恋爱、创业梦、电竞之路、考研之路……），抽到第 1 环后，后续学期按顺序出第 2、3 环，有始有终。
4. 大事件之后还有 **2 件随机小事**：食堂鸡腿特别大、室友打呼噜、晚霞特别美……200 件小事，短平快，丰富日常。
5. 8 个学期过完，毕业。结局由你的属性决定。

## 内容量（v1.1）

- 6 个学期行动
- **220 个大事件**（军训、四级、运动会、表白墙、彩票、散伙饭……按学年出现）
- **200 件随机小事**（每学期 2 件）
- **15 条连锁剧情 × 3 环 = 45 个节点**（恋爱、创业、电竞、考研、兼职、社团、健身、学霸、主播、旅行、流浪猫、乐队、写小说、摄影、志愿者）
- **32 个结局**
- **25 个成就**
- 1 个赌一把事件（彩票：12% 概率中 500）和 1 个刮刮乐（15% 概率中 100）

一局能玩到的事件组合数是 v1.0 的几千倍以上：大事件池 40→220，小事 0→200，每学期 encounters 2→4（1 行动 + 1 大事件 + 2 小事）。

## 文件结构

- `index.html` — 结构（开始 / 游戏 / 结局三个界面）
- `styles.css` — 样式（暖色卡片风）
- `data.js` — 内容数据：行动、事件、小事、连锁剧情、结局、成就和判定
- `game.js` — 游戏逻辑：流程、属性、存档、结局图鉴、成就

## 本地运行

直接用浏览器打开 `index.html` 就行；或者部署到 GitHub Pages。
