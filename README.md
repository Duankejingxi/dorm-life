# 宿舍人生 · 大学四年模拟器

> 你 18 岁，考上大学，住进宿舍。四年，8 个学期，每学期选一个行动，再遇到一件意想不到的事。毕业那天，看看你活成了什么样。

纯前端文字模拟游戏，打开就能玩，不用下载，不用注册，不用联网。

## 怎么玩

1. 输入名字，点「开始大一」。
2. 每学期选 **1 个行动**：上课学习 / 打工赚钱 / 健身运动 / 打游戏 / 社交聚会 / 摆烂躺平。
3. 再处理 **1 个随机事件**：室友半夜开黑、食堂新开麻辣烫、捡到校园卡、表白墙挂你……每个事件 2–3 个选择，后果各不相同。
4. 8 个学期过完，毕业。结局由你的属性决定。

## 六项属性

| 属性 | 说明 |
| --- | --- |
| ❤️ 健康 | 归零会病倒休学 |
| 🧠 智力 | 学习、保研、考研的本钱 |
| ✨ 魅力 | 社交、面试、创业的本钱 |
| 😊 快乐 | 开心最重要，但光快乐毕不了业 |
| 💰 金钱 | 生活费、打工、聚餐、剁手……欠债太多会退学 |
| 📚 学分 | 上课、考试攒的，毕业的硬指标 |

## 结局（10 个）

| 结局 | 大概条件 |
| --- | --- |
| 🤒 病倒休学 | 健康归零（提前结束） |
| 💸 欠债退学 | 欠债超过 500（提前结束） |
| 📉 延毕一年 | 学分 < 20（毕不了业） |
| 🎓 保研成功 | 学分 ≥ 40 且智力 ≥ 85 |
| 📚 考研上岸 | 学分 ≥ 35 且智力 ≥ 75 |
| 💼 大厂 Offer | 智力 ≥ 80 且魅力 ≥ 75 |
| 🚀 创业成功 | 金钱 ≥ 5000 且魅力 ≥ 70 |
| 🏅 校队明星 | 健康 ≥ 85 且魅力 ≥ 70 |
| 😌 快乐躺平 | 快乐 ≥ 90 |
| 🎓 平凡毕业 | 以上都不是 |

解锁过的结局存在本机（结局图鉴），换个活法能解锁更多。

## 内容

- 6 个学期行动
- 40 个随机事件（军训、四级、运动会、表白墙、彩票、散伙饭……按学年出现）
- 1 个赌一把事件（彩票：12% 概率中 500）
- 10 个结局

## 文件结构

- `index.html` — 结构（开始 / 游戏 / 结局三个界面）
- `styles.css` — 样式（暖色卡片风）
- `data.js` — 内容数据：行动、事件、结局和判定
- `game.js` — 游戏逻辑：流程、属性、存档、结局图鉴

## 本地运行

直接用浏览器打开 `index.html` 就行；或者部署到 GitHub Pages。
